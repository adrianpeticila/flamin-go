# Flamin.go Viral Data Bomb Spec: Agent ROI Wrapped

**Concept:** Programmatic monthly and quarterly "Agent Fleet Wrapped" visual cards summarizing autonomous work accomplished.  
**Viral Loop:** Operators share their high-contrast, data-dense achievement cards on X (Twitter), LinkedIn, Discord, and internal Slack channels.  
**Inspiration:** Spotify Wrapped, Linear Year in Review, GitHub Skyline.

---

## 1. Metric Payload Definition

The Flamin.go telemetry pipeline generates a deterministic monthly snapshot for each account:

```json
{
  "period": "August 2026",
  "account_handle": "swarm_operator_42",
  "metrics": {
    "total_agent_interactions": 48920,
    "human_hours_saved": 142.5,
    "dollars_saved_vs_seats": 2850.00,
    "competitors_monitored": 18,
    "documents_sanitized": 340,
    "decision_dag_nodes_logged": 1240,
    "top_performing_tool": "flamingo_competitor_diff",
    "compute_efficiency_score": "99.4%"
  }
}
```

---

## 2. Card Visual Layout & Aesthetics

- **Dimensions:** 1200 x 675 px (optimized for 16:9 social previews on X and LinkedIn).
- **Color Palette:** Deep void background (`#090a0f`), electric magenta accent (`#ff4071`), cyber emerald (`#10b981`), stark mono typography (`JetBrains Mono` / `SF Mono`).
- **Layout Structure:**
  - Header: `FLAMIN.GO FLEET WRAPPED // [PERIOD]`
  - Hero Stat: Large centered numerical callout: `142.5 HOURS SAVED` or `$2,850 VALUE CREATED`.
  - Grid Breakdown: 4 telemetry tiles (Interactions, Competitor Audits, Cleaned Docs, Provenance Nodes).
  - Footer Watermark: `Generated by Flamin.go Headless Swarm | flamin.go/wrapped`.

---

## 3. Rendering Pipeline

Cards are rendered serverless at the edge using SVG templates rasterized via `@resvg/resvg-js` on Cloudflare Workers:

1. **Trigger:** On the 1st of every month, an automated cron generates the card and posts a webhook notification to the operator's Slack/Discord.
2. **Social Export:** Operator clicks *"Share to X"* or *"Copy Clean PNG"*.
3. **Deep Link:** Shared link routes to `https://flamin.go/w/[short_id]`, which displays the interactive card with an immediate CTA: *"Build your autonomous fleet on Flamin.go"*.

---

## 4. Viral Growth Targets

- **Share Rate:** > 12% of active fleet operators sharing card publicly each month.
- **Referral Conversion:** 1 paid trial activation per 4 public card impressions on developer social feeds.
